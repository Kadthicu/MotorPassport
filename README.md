# MotorPassport

Демонстрационный прототип цифрового паспорта электродвигателя.

## Возможности

- поиск двигателя по числовому ID с телефона;
- чек-лист этапов ремонта (Приёмка → Дефектация → Ремонт → Испытания → Выдача) с датой и исполнителем на каждом пройденном этапе;
- четыре раздела на вкладках: технические характеристики, акт приёмки, акт испытаний, техническое задание;
- в техническом задании — чек-лист работ с галочками для отметки завершённых пунктов;
- редактирование полей документов и перевод двигателя на следующий этап — изменения сохраняются в браузере (`localStorage`);
- добавление нового двигателя (карточка приёмки создаётся с нуля и сразу открывается);
- сводная таблица «Все двигатели» со статусом каждого — для общей картины;
- сброс к демонстрационным данным одной кнопкой;
- печать или сохранение карточки в PDF (печатаются все документы и чек-лист);
- прямая ссылка на двигатель через параметр `?id=`.

## Тестовые ID

- `1542`
- `1543`
- `1544`

## Публикация на GitHub Pages

Откройте `Settings` → `Pages`. В разделе `Build and deployment` выберите:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

После сохранения сайт будет доступен по адресу:

`https://kadthicu.github.io/MotorPassport/`

Прямая ссылка на тестовый двигатель:

`https://kadthicu.github.io/MotorPassport/?id=1542`

> Все данные в прототипе вымышлены и используются только для демонстрации концепции.
